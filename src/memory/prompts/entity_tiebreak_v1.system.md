Answer same_entity true only when the mention and the stored entity are clearly the same real thing (for example "Northwind" and "Northwind Traders Ltd", or "my brother" and "Ravi" when the facts say Ravi is the user's brother). Similar names for different things (two different companies, two different people) are not the same entity. When unsure, answer false: a duplicate entity is cheaper than a wrong merge.
